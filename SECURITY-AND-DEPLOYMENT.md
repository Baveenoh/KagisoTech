# KagišoTech security/deployment checklist

Before production: enable HTTPS/HSTS; use secure hosting; connect forms to a reputable backend; add server-side validation/rate limiting/anti-spam; configure CSP and related security headers; keep software and dependencies updated; maintain tested backups; use MFA/least privilege for admin accounts; never expose API keys in frontend code; publish final privacy/terms notices; review third-party map, form, analytics and AI data handling.

The demo is a front-end prototype and does not itself provide a firewall, DDoS protection, malware scanning, secure database or secure backend.
